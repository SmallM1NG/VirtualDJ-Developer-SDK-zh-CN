用于VDJ插件的GUID全局唯一标识符列表


DllGetClassObject(const GUID &rclsid, const GUID &riid, void** ppObject) 函数根据插件中使用的类标识符CLSID 和组件接口IID，在 VDJ中加载插件的类（通过/根据 ppObject）。
也就是说，VDJ会在内部列出所有可用的全局唯一标识符GUID，直到与您的插件匹配为止。

例如在C++中（以DSP插件为例）：
// 这是COM对象的标准DLL加载器。
// 如果a和b匹配，memcmp(a, b, sizeof(XXXX)) 函数返回 0。
// 如果插件返回CLASS_E_CLASSNOTAVAILABLE，则表示该插件与当前VDJ版本不兼容

HRESULT VDJ_API DllGetClassObject(const GUID &rclsid,const GUID &riid,void** ppObject)
{

	if (memcmp(&rclsid,&CLSID_VdjPlugin8,sizeof(GUID))==0 && memcmp(&riid,&IID_IVdjPluginDsp8,sizeof(GUID))==0)
	{
		*ppObject = new CVDJClass8();
	}
	else if (memcmp(&rclsid,&CLSID_VdjPlugin6,sizeof(GUID))==0 && memcmp(&riid,&IID_IVdjPluginDsp,sizeof(GUID))==0)
	{
		*ppObject = new CVDJClass6();
	}
	else
	{
		return CLASS_E_CLASSNOTAVAILABLE;
	}

	return NO_ERROR;
}

在这个例子中，CVDJClass8将在VDJ 8上调用，CVDJClass6将在VDJ 7上调用，这样就可以在每次更改VDJ SDK版本时保持兼容性。
