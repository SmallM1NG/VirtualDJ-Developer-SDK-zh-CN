使用SDK v8开发的视频转换插件（2 碟盘）


下面是一个开始开发插件"MyPlugin8"的示例。 我们使用"CMyPlugin8"类来定义我们的对象，但你也可以使用你想要的。 文件 "Main.cpp"是对象"CMyPlugin8"的调用者，是与VDJ通信的入口。

在本例中，您需要在项目中包含SDK v8中的以下文件：vdjPlugin8.h（所有插件的基本通用基类）和vdjVideo8.h（所有视频插件的基类）
您也可以使用其他编译器，但请在电脑上找到一个Visual Studio C++项目示例。 它会生成一个.dll 文件
在本示例中，请将所有文件复制到同一文件夹中。

Main.cpp:
#include "MyPlugin8.h"

HRESULT VDJ_API DllGetClassObject(const GUID &rclsid,const GUID &riid,void** ppObject)
{
	if (memcmp(&rclsid,&CLSID_VdjPlugin8,sizeof(GUID))==0 && memcmp(&riid,&IID_IVdjPluginVideoTransition8,sizeof(GUID))==0)
	{
		*ppObject=new CMyPlugin8();
	}
        else
	{
		return CLASS_E_CLASSNOTAVAILABLE;
	}

	return NO_ERROR;
}
